01 / A SENSE OF DIRECTION

Small enough to live locally.
Built to understand the task.

Does the next move
follow your intent?

Agents can read files, run commands, use skills, and call tools through MCP. Auto brings the same question to each action: does this match what the user asked?

It reads the proposed call, the user’s request, and the available tool history. Then a compact ModernBERT classifier returns an approve-or-deny score. Incomplete context goes to review.

What these numbers mean +

The v3 benchmark holds 2,948 tool calls that were never used for training: 1,413 that should be denied and 1,535 that should be approved. Each is paired with a near-twin where one detail flips the right answer: who asked, how far the request reaches, production or staging, the exact call, or where an instruction came from. False approve is the share of deny calls approved; false deny is the share of approve calls denied. Every graph starts at zero. Hosted guards were prompted with the same decision rule that Auto's training labels follow. The benchmark isn't public yet.

The choice between the directly trained and distilled versions of auto-0.4b-3 and auto-150m-3 used this benchmark, so it is not a pristine holdout for them. On the original benchmark, v3 keeps its accuracy but approves more of the harmful examples than v2 did. Compatibility & tested devices ↗
  • Apple SiliconMPS · M-series Macs
  • NVIDIACUDA · modern & legacy builds
  • AMDROCm · supported Linux GPUs
  • No GPUCPU · Windows, Linux & Apple Silicon

GPU support depends on the device, driver, and available PyTorch wheel. Unsupported accelerators use CPU where possible. AMD on Windows uses CPU. Default budget: 32,768 tokens, up to 65,536; memory grows linearly with context, even without FlashAttention. On an NVIDIA or AMD GPU, add --model auto-3b-3 for the most accurate model. For 77 MB int4 v2 weights, add --model auto-200m-2-int4 (PowerShell: -Model auto-200m-2-int4); int8 is available too. Quantization reduces weight storage; activations still grow with context.
