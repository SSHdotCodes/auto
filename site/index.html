01 / A SENSE OF DIRECTION

Small enough to live locally.
Built to understand the task.

Does the next move
follow your intent?

Agents can read files, run commands, use skills, and call tools through MCP. Auto brings the same question to each action: does this match what the user asked?

It reads the proposed call, the user’s request, and the available tool history. Then a compact ModernBERT classifier returns an approve-or-deny score. Incomplete context goes to review.

What these numbers mean +

Evaluation uses the fixed Approve-or-Deny benchmark revision a38b625913dd46ca9702063f1597c979e6ace34e: 1,401 deny examples and 1,599 approve examples. False approve is the fraction of deny examples approved; false deny is the fraction of approve examples denied. Every graph starts at zero.

The new model was trained with short- and long-context supervised fine-tuning. Conditional distillation was skipped after it exceeded the teacher on this evaluation. Because the benchmark informed that choice, it is not a pristine, one-use holdout. The 24 tool probes below are authored illustrations, not another independent accuracy benchmark. Compatibility & tested devices ↗
  • Apple SiliconMPS · M-series Macs
  • NVIDIACUDA · modern & legacy builds
  • AMDROCm · supported Linux GPUs
  • No GPUCPU · Windows, Linux & Apple Silicon

GPU support depends on the device, driver, and available PyTorch wheel. Unsupported accelerators use CPU where possible. AMD on Windows uses CPU. Default budget: 32,768 tokens, up to 65,536; memory grows linearly with context, even without FlashAttention.
